# Todo List

Proyecto del currículo Full Stack JavaScript de [The Odin Project](https://www.theodinproject.com/lessons/node-path-javascript-todo-list).

Actualmente en desarrollo.

## 🎯 Objetivo

Construir una aplicación para crear, visualizar, editar y eliminar tareas, organizándolas en proyectos, aplicando:

- Objetos para representar tareas con título, descripción, fecha límite y prioridad.
- Arrays para agrupar tareas en proyectos, con un proyecto por defecto y la posibilidad de crear otros.
- Módulos ES6 para separar la lógica de la aplicación de la manipulación del DOM.
- Manipulación del DOM y gestión de eventos para interactuar con la aplicación.
- Persistencia de datos con `localStorage` y JSON.
- Webpack y npm para gestionar las dependencias y preparar el proyecto para desarrollo y producción.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
- Webpack
- npm
